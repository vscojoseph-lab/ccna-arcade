Chapter 1: Physical Layer & Network Hardware for Absolute Beginners

Know Your Hardware Before You Build

If you've never touched physical networking gear, start here! These are the core building blocks you'll see in the CCNA exam and real data centers:

💻 PC / Host

Your desktop or laptop. It contains a NIC (Network Interface Card) with a physical port to plug in cables so it can talk to the network.

🖲️ Switch (Layer 2)

The traffic cop inside a single office. It connects devices together in the same local network (LAN) and uses MAC addresses to forward data smartly.

📡 Hub (The "Dumb" Switch)

An older, obsolete device. If data comes in one port, a hub blindly blasts it out to *every* other port. This causes massive data collisions!

🌐 Router (Layer 3)

The post office of the network. It connects *different* networks together (like your home network to the Internet) using IP addresses.

🔌 RJ-45 & Copper Cable

The standard clear plastic clip connector on the end of an Ethernet network cable (like Cat6) used to plug computers into switches.

💡 Fiber Optic Cable

Uses pulses of light through glass strands instead of electricity. Used for ultra-fast, long-distance connections between buildings.
