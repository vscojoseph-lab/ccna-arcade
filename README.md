# CCNA Arcade - Professional NetAcad Suite

An simple interactive networking academy training suite and packet tracer simulation tool designed to help students understand Cisco CCNA concepts through gamified challenges, topology validations, and certification quizzes.

## 🚀 Features
- **Interactive Packet Tracer Workspace:** Drag-and-drop devices (Routers, Switches, Host PCs), wire physical links, and test topologies with real-time graph verification.
- **Curriculum Modules:** Structured lessons covering OSI layers, media types, pinouts, and hardware specifications.
- **Certification Exam Suite:** Multiple-choice technical questions with detailed answer breakdowns.
- **Central Module Hub:** Seamless navigation across independent modules using a consistent UI architecture.
