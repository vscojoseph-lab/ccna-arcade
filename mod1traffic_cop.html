CURRICULUM MODULE: LEVEL 1.1 - PHYSICAL LAYER & GATEWAYS

Welcome beginner network engineer! Imagine a postal system: Hosts (PCs) write letters, Switches deliver mail within the same local building (LAN), and Routers are post offices sending mail across separate cities (WAN/Internet). At the Physical Layer (OSI Layer 1), data bits are converted into electrical pulses, light flashes, or radio waves.

1. Understanding Core Devices

• Host PC: An end-user node generating traffic.
• Layer 2 Switch: Connects devices on the same LAN using MAC addresses.
• Router: Acts as the gateway between different networks using IP addresses.

2. Performance Metrics

• Bandwidth: Maximum theoretical capacity (e.g., 1 Gbps).
• Throughput: Actual measured speed right now.
• Goodput: Usable application speed after removing headers.

3. Copper Media & Crosstalk

• UTP Copper Cables: Unshielded twisted pairs.
• Twisting: Cancels out outside electromagnetic interference (EMI).

4. Fiber-Optic Technologies

• Single-Mode (SMF): Lasers, long distance (100km).
• Multimode (MMF): LEDs, datacenters (550m).
