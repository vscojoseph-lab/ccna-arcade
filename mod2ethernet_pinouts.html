Stage 1 • Level 1.2: Ethernet Pinouts (Cisco NetAcad ITN Deep-Dive)

Welcome to OSI Layer 1: Cable Pinouts. To master Cisco infrastructure deployments, you must map structural cable terminations correctly based on device transmission interfaces managed by the TIA/EIA-568 standard.

1. T568A vs. T568B Standards

• T568A Color Order: Green/White, Green, Orange/White, Blue, Blue/White, Orange, Brown/White, Brown.
• T568B Color Order: Orange/White, Orange, Green/White, Blue, Blue/White, Green, Brown/White, Brown.
• The Core Difference: Pins 1 and 2 (Transmit) swap places with Pins 3 and 6 (Receive) between these layout schemes.

2. Straight-Through Cables

• Wiring Scheme: Both alternative cable endpoints utilize identical pin standards (either T568A to T568A, or T568B to T568B).
• Implementation: Connects host targets operating at different layers of the OSI model.
• Device Paths: PC-to-Switch, Switch-to-Router, Switch-to-Access Point, Router-to-Server.

3. Crossover Cables

• Wiring Scheme: One end uses the T568A standard layout while the opposite end switches to the T568B pin configuration.
• Implementation: Connects host devices operating at the same layer of the OSI framework.
• Device Paths: Switch-to-Switch, Router-to-Router, PC-to-PC, and PC-to-Router (PCs and Routers transmit data on identical pin structures!).

4. Auto-MDIX Technology

• Function: A Cisco device option that automatically detects cable configuration types and configures interfaces accordingly.
• CCNA Exam Warning: You must always assume Auto-MDIX is disabled or missing unless a test question explicitly states otherwise!
